# GitHub 题库来源评估

评估日期：2026-07-23。

## 引入原则

外部题库必须满足：

1. 许可证和原始题目使用范围明确；
2. 题干、答案可以稳定解析；
3. 能补充章节、知识点、难度和标准解析；
4. 转换为项目 JSON 格式后，再经过校验、去重和人工抽查；
5. 来源写入每道题的 `source` 字段。

## 候选来源

### AGIEval

- 地址：https://github.com/ruixiangcui/AGIEval
- 仓库许可证为 MIT，包含中国高考多个学科的选择题。
- 仓库要求数据使用遵循原始数据许可证；多数记录缺少标准解析、章节和知识点。
- 结论：仅作为候选原始题源，不直接导入生产题库。

### GAOKAO-Bench

- 覆盖高考主要学科，公开资料标注为 Apache-2.0。
- 数据面向模型评测，需要逐题补充解析、知识点并核对原始内容授权。
- 结论：适合制作一小批人工审核题，不适合无审核批量导入。

### OlympiadBench

- 地址：https://github.com/OpenBMB/OlympiadBench
- 仓库许可证为 MIT，有中文数学、物理题、答案和解析。
- 大量题目属于竞赛级或多模态题，难度高于当前准高三 MVP。
- 结论：暂不用于常规训练。

### gaokaomath

- 地址：https://github.com/deekur/gaokaomath
- 整理内容采用 CC BY 4.0，但仓库说明试题版权归命题方或出版方所有。
- 内容以 PDF 为主，需要 OCR、公式校对、切题和答案核验。
- 结论：适合人工参考，不进行自动抓取导入。
