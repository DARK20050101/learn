# AGIEval 题源审计与使用边界

## 审计结论

本批次采用 AGIEval v1.1 中少量、可独立验证且适配当前知识目录的 2023 年高考客观题。
题源仓库固定到提交：

`84ab72d94318290aad2e4ec820d535a95a1f7552`

AGIEval 仓库代码采用 MIT License，但仓库 README 明确要求数据集使用者同时遵守原始数据的
许可要求。因此，“代码仓库开源”不等同于“其中全部试题可不受限制再分发”。本项目只进行小批量、
可追溯的教学测试使用，保留原卷名称、数据集、行号和固定提交号；在扩大公开发布范围前，仍需完成
题目版权和使用授权复核。

来源：

- AGIEval 仓库：https://github.com/ruixiangcui/AGIEval

## 与青海考生的适配

青海 2026 年普通高考采用“3+1+2”模式。本批题目优先采用 2023 年全国乙卷（青海旧高考阶段
直接使用）和 2023 年新课标卷中的基础主干知识，用于衔接当前课程和训练方式。

## 质量控制

AGIEval v1.1 提供题干、选项和标签，但不提供可直接用于本系统的标准解析。发布流程不得直接信任
标签，必须执行：

1. 固定数据集提交号，防止上游内容漂移。
2. 排除题干、公式、选项缺失或知识点无法准确映射的记录。
3. 对每题独立推导答案，再与数据集标签核对。
4. 人工编写解析，解析必须说明关键判断或计算过程。
5. 运行 `question_bank lint` 与数据库感知的 `question_bank verify`。
6. 使用事务化发布命令先 dry-run，再正式导入；任何冲突均回滚。

## 本批次取舍

- 纳入：11 道物理、化学、生物单选题。
- 排除：题干能量数量级缺失、核反应选项缺失、科学记数法指数疑似损坏等记录。
- 不采用 OlympiadBench 作为本批来源：其题目整体更偏竞赛、开放题和多模态，高难度比例较高，
  不适合直接进入当前“每日 6 题”基础闭环。
