# 青海物化生方向六科高考题采集计划

版本：v1  
日期：2026-07-30  
状态：题源已盘点，尚未导入数据库

## 1. 适用学生与科目

目标学生为青海西宁、物理方向并选择化学和生物学的准高三学生。

六科固定为：

1. 语文
2. 数学
3. 英语
4. 物理
5. 化学
6. 生物学

青海自2025年起采用“3+1+2”模式。语文、数学、外语属于全国统一考试科目；物理为首选科目；化学、生物学为再选科目。

## 2. 试卷适配规则

### 2.1 第一优先级：青海当前同卷

- 语文、数学、英语：2025年及以后青海适用的全国二卷。
- 物理、化学、生物学：2025年及以后适用于陕西、山西、宁夏、青海的西北卷。
- 青海省新高考适应性测试卷可作为模拟训练来源，但必须标记为“适应性测试”，不得标记为正式高考真题。

### 2.2 第二优先级：同课程标准的近年新高考卷

当青海同卷题量不足时，可选择其他省份的新高考真题补充知识点训练。题目来源必须保留原省份、年份和卷型，不得改称“青海真题”。

### 2.3 第三优先级：青海历史适用卷

2024年及以前青海使用的全国甲卷、全国乙卷或理综拆分题，可用于知识点专项训练。由于考试模式已经变化，这些题不得用于模拟当前完整卷型，也不得与2025年后的青海选考卷混淆。

## 4. 当前系统阻塞项

现有标准知识点目录只覆盖数学、物理、英语，题库质量CLI的学科参数也只接受这三科。因此：

- 可以继续收集语文、化学、生物原始题源；
- 不能把这三科转成正式题库JSON并导入；
- 必须先完成语文、化学、生物MVP知识点目录；
- 语文材料题、英语篇章题需要保留“材料—子题”关系，当前单题结构不应强行拆成失去上下文的题；
- 含图、实验装置、表格的物化生题必须保留原始资源，当前缺图题禁止上线。

## 5. 首批生产规模

第一批不追求整卷全量录入，建议从适合手机每日训练的客观题开始：

| 学科 | 首批目标 | 优先内容 |
|---|---:|---|
| 语文 | 20 | 语言文字运用、文言基础、现代文单题 |
| 数学 | 30 | 函数、数列、三角、导数、概率统计 |
| 英语 | 25 | 阅读、完形、语法填空，不拆散必要上下文 |
| 物理 | 25 | 力学、电磁学、实验基础 |
| 化学 | 25 | 基本概念、反应原理、元素化学、实验 |
| 生物学 | 25 | 细胞、遗传、稳态、生态、实验 |

首批共150题。每科单独形成draft和审核报告，不一次性导入。

## 6. 采集到上线的门禁

每道题必须经历：

```text
题源登记
→ 卷型与青海适配确认
→ 原始材料完整性检查
→ 结构化草稿
→ 标准知识点映射
→ 独立作答核验
→ 答案与解析审核
→ lint / verify / coverage / difficulty
→ 人工批准
→ 事务化发布
```

以下情况直接退回：

- 来源网址、年份、卷型不明；
- 把适应性测试或模拟题标成高考真题；
- 缺图、缺表、缺阅读材料；
- 标准答案不能独立验证；
- 解析只是答案复述；
- 语文或英语子题脱离材料后无法作答；
- 化学方程式、物理量单位、生物学术语存在OCR错误；
- 无可用的正式三级知识点。

## 7. 来源记录格式

正式草稿的 `source` 建议使用：

```text
高考真题|year:2025|region:青海适用|paper:全国二卷|subject:数学|question:7|url:<来源页>
```

```text
高考真题|year:2025|region:陕晋宁青|paper:西北卷|subject:物理|question:3|url:<来源页>
```

GAOKAO-Bench历史候选使用：

```text
GAOKAO-Bench|year:<年份>|index:<索引>|commit:6dbb24f8d843
```

## 8. 推荐执行顺序

1. 建立语文、化学、生物MVP三级知识点目录。
2. 扩展只读题库CLI，使其识别六科。
3. 收集并冻结2025年青海适用六科试卷来源清单。
4. 先生产数学、英语、物理各10题，验证现有范式。
5. 再生产语文、化学、生物各10题，验证新知识点目录。
6. 按每批20—30题进行AI初审和人工复核。
7. 全部通过后使用现有事务化发布流程上线。
